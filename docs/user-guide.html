LessMB 使用指南

版本 1.0.0 · Windows 64 位便携版

LessMB 是一款批量图像压缩与转换工具。支持超过 100 种不同格式图像的缩放与转换。

简介

LessMB 基于 ImageMagick 引擎，可一次性处理大量图像：转换格式、调整尺寸与分辨率、旋转翻转、批量重命名输出等。主程序为 lessmb.exe，无需安装即可解压使用。

本指南中的界面用语与软件内简体中文翻译保持一致，便于对照操作。

安装与运行

  1. 解压发布包 LessMB-1.0.0-win64.zip 到任意目录（建议路径不含中文或特殊字符）。
  2. 进入解压后的文件夹，双击 lessmb.exe 启动。
  3. 首次运行会自动创建配置文件；若在同目录下存在可写的 settings 文件夹，则使用便携模式保存设置。
请保持 lessmb.exe 与 loc/、modules/ 等依赖文件在同一目录，不要单独移动可执行文件。

便携版目录结构

LessMB-1.0.0-win64/ ├── lessmb.exe # 主程序 ├── lessmb.ico # 程序图标 ├── loc/ │ └── converseen_zh_CN.qm # 简体中文语言包 ├── modules/ # ImageMagick 编解码模块 ├── imageformats/ # Qt 图像插件 ├── platforms/ # Qt 平台插件 ├── settings/ # （可选）便携模式配置目录 │ └── .lessmb.conf # 用户设置 └── … # Qt 与 ImageMagick 运行库

若未使用便携模式，配置文件保存在用户目录：%APPDATA%\lessmb\.lessmb.conf。

界面语言

LessMB 首次运行默认使用简体中文。语言文件位于 loc/converseen_zh_CN.qm，请勿删除。

如需改为英文或其他语言：

  1. 打开 文件 → 设置。
  2. 在 语言 中选择目标语言。
  3. 点击 确定 并按提示 重新启动 LessMB。

导入图像

通过菜单 文件 或工具栏可将图像加入待处理列表：

操作说明快捷键
打开图像打开文件选择框，导入图像（替换当前列表）Ctrl+O
添加图像在现有列表基础上追加图像Ctrl+Alt+O
导入目录扫描文件夹内所有支持的图像；可询问是否包含子文件夹—
导入 PDF 文件将 PDF 各页作为图像导入（需 Ghostscript，见下文）—
导入 Windows 图标文件导入 *.ico / *.icon 中的子图像—

多页文档

导入 PDF、ICO 等多页文件时，会弹出 导入多页文档 对话框。勾选要导入的页或子图像，可使用 全部勾选 / 全部取消勾选，确认后点击 导入。

图像列表

主窗口列表显示：待转换、状态、文件名、图像格式、图像大小、分辨率、大小、路径等列。只有勾选了 待转换 的图像才会参与批量处理。

  • 勾选 / 取消勾选：作用于当前选中项
  • 全部勾选 / 全部取消勾选：作用于全部项目
  • 反转已勾选项目：Ctrl+I
  • 移除图像 / 清空列表：从列表中删除

格式转换与图像设置

格式转换

在 格式转换 区域，从 转换为： 下拉框选择目标格式。选择 不更改格式 则仅执行缩放等操作而不改变文件类型。

若输出格式不支持写入，转换时会提示错误并跳过该文件。

图像设置

点击 图像设置 按钮打开对话框，可调整：

  • Jpeg 压缩等级：质量 1–100（1 压缩率最高、100 质量最好）
  • Png/Mng 压缩级别：质量 0–9（PNG 为无损压缩，提高级别不会降低画质）
  • WebP：无损压缩、压缩方法、质量、抖动等
  • 插值：缩放时使用的滤波器
  • 删除图像的元数据：输出时去除 EXIF 等元数据以减小体积

透明背景

勾选 替换透明背景 并 选择颜色，可将 PNG/WebP 等格式的透明区域替换为指定背景色（常用于输出 JPEG）。

操作面板

通过菜单 操作 → 操作面板 显示或隐藏右侧操作区。选中列表中的图像后，可在此预览并设置变换参数。

预览

勾选 显示预览 可实时查看效果。预览区显示图像格式、文件大小、图像尺寸、分辨率等信息。

缩放

勾选 缩放 后设置 宽度 与 高度：

  • 单位可在 px（像素）与 %（相对原图百分比）之间切换
  • 保持纵横比：按比例缩放，避免变形
  • 将一边设为 0 可只固定另一边，另一边自动计算（如高度 800、宽度 0 → 高度固定 800 像素，宽度按比例计算）

分辨率

勾选后可设置 水平分辨率 与 垂直分辨率（dpi），用于印刷或文档输出场景。

旋转和翻转

  • 旋转：不旋转、+90°、-90°、180°
  • 翻转：不翻转、水平翻转、垂直翻转

输出设置

保存位置

  • 保存到：指定输出文件夹，可点击 ... 浏览或 打开输出目录
  • 原图像目录：勾选后输出到每张原图所在文件夹，忽略上方自定义路径

重命名

勾选 重命名： 后可选择：

  • 前缀/后缀：在文件名前或后添加文字（默认示例 #_副本）
  • 自动编号：按序号重命名，可设置 开始于： 的起始数字

若输出目录不存在，程序会询问是否创建。

文件覆盖

主窗口 文件覆盖设置 与 设置 → 文件覆盖 共同决定同名文件的处理方式：

选项行为
始终询问同名时弹出对话框，可重命名或覆盖
跳过现有文件自动跳过，保留目标目录中已有文件
覆盖现有文件直接覆盖，原文件将被永久删除，请谨慎使用

全局设置中还可选择 覆盖前进行确认 或 覆盖所有已存在图像文件，作为默认策略。

PDF 转换（Windows）

官方发布包已内置 Ghostscript（位于 ghostscript/ 目录），解压即可使用，无需用户自行安装。

LessMB-1.0.0-win64/ ├── lessmb.exe ├── ghostscript/ │ ├── bin/ │ │ └── gswin64c.exe │ └── Resource/ └── loc/ └── converseen_zh_CN.qm

导入 PDF

通过 文件 → 导入 PDF 文件 将 PDF 各页加入列表。分析大文件时可能提示「正在分析文件。这可能需要花费一些时间，请耐心等待…」。

说明：LessMB 将 PDF 各页转为图像后再压缩/转换，并非直接对 PDF 二进制做重压缩。若只需缩小体积，请导入后选择 JPEG/WebP 等格式并调整压缩参数。

若提示缺少 Ghostscript

请确认 ghostscript/bin/gswin64c.exe 与 lessmb.exe 在同一发布包内且未被杀毒软件隔离。也可从 ghostscript.com 安装 64 位版本并加入 PATH。

开始转换

  1. 确认列表中已勾选需要处理的图像
  2. 设置目标格式、输出目录及操作面板参数
  3. 点击工具栏 开始转换 或按 F5

转换过程中会显示 转换状态 对话框，包含总计、已转换、转换错误数量，可随时 停止。完成后可 打开输出目录 或 打开所有输出目录 查看结果。

命令行

在 lessmb.exe 所在目录打开命令提示符，可使用以下参数：

参数说明
-p / --supported-formats打印所有可读/可写的支持格式列表
-l list.txt / --list从文本文件读取待导入的文件路径列表并加载到界面
-h / --help显示帮助信息
-v / --version显示版本号
示例
lessmb.exe -p
lessmb.exe -l D:\images\list.txt

list.txt 中每行一个图像文件的完整路径。

常见问题

界面仍是英文？

首次运行应默认中文。若仍为英文，请在 设置 → 语言 选择简体中文并重启；或删除旧版配置文件 .lessmb.conf 后重新启动。确认 loc/converseen_zh_CN.qm 存在。

提示「未勾选任何图像」或「没有需要转换的图像」？

列表左侧 待转换 列须勾选；且列表不能为空。

提示「请指定输出目录」？

取消勾选「原图像目录」后，必须在「保存到」中指定有效文件夹。

转换后文件被跳过？

可能因「跳过现有文件」策略或目标文件已存在。可改为「始终询问」或更换输出目录/重命名规则。

如何查看支持的格式？

运行 lessmb.exe -p，或在「关于 LessMB」中查看 ImageMagick 版本信息。

导入 PDF 时提示需要 Ghostscript？

请使用包含 ghostscript/ 目录的完整发布包，或参考 PDF 转换 手动安装 Ghostscript。
